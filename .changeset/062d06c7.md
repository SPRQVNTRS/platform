Add new AWS package with Lambda, S3, and DynamoDB client wrappers.

Features:
- AwsManagerLambda: Async Lambda function invocation
- AwsManagerS3: S3 operations (get, put, list, exists, delete)
- AwsManagerDynamoDb: DynamoDB operations (getItem, putItem, query, scan)
- Shared AWS configuration types and utilities
